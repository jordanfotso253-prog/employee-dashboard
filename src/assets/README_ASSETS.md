# Employee Dashboard Assets

Recommended usage:
- logo.svg -> navbar/sidebar/logo
- favicon.svg -> browser favicon
- login-illustration.svg -> login page
- empty-employees.svg -> empty employee list state
- error-illustration.svg -> API error state

The employee avatars should come from DummyJSON user data (`image` field), so you do not need to manually download 30+ employee photos.

Icons such as dashboard, users, search, edit, trash, settings and logout can be provided by `lucide-react`, so separate icon image files are unnecessary.

Suggested folders:
src/assets/
  logo.svg
  login-illustration.svg
  empty-employees.svg
  error-illustration.svg
  favicon.svg
